
# Stellar Burgers — юнит-тесты

## Описание проекта

Автоматизированные юнит-тесты для класса `Burger` приложения Stellar Burgers.

## Реализованные проверки

- Установка булочки
- Добавление ингредиента
- Удаление ингредиента
- Обработка некорректного индекса при удалении
- Перемещение ингредиентов с параметризацией
- Расчёт стоимости бургера с ингредиентами
- Расчёт стоимости бургера без ингредиентов
- Формирование чека

Для изоляции тестируемого класса используются моки (`unittest.mock.Mock`).

## Результаты

- 10 успешно пройденных тестов
- Покрытие класса `Burger` — 100% по строкам кода

## Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

## Запуск тестов

```bash
python -m pytest -v
```

## Проверка покрытия и создание HTML-отчёта

```bash
python -m pytest --cov=praktikum.burger --cov-report=term-missing --cov-report=html
```

HTML-отчёт создаётся в `htmlcov/index.html`.
